READY TO RUN - ASP.NET Core MVC (.NET 8)

1. Extract the ZIP.
2. Open the MyMvcLandingPage folder in VS Code or Visual Studio.
3. Open terminal in that folder.
4. Run: dotnet restore
5. Run: dotnet run
6. Browser should open automatically. If not, open http://localhost:5055

Requirement: .NET 8 SDK installed.
